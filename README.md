# Учебный репозиторий

Репозиторий создан в рамках обучения по специальности **«Информационные технологии»**.

Здесь собраны практические и домашние задания, учебные проекты связанные с изучением программирования, информационных технологий и разработки ПО.

**Направление обучения:** программирование и разработка программного обеспечения.
