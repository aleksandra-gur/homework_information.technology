Здесь собраны практические и домашние задания, а также учебные проекты, связанные с программированием и разработкой программного обеспечения.

## Содержание

- [Курсовая работа «Огранка»](./kursovaya_rabota/) — описание проекта, его функциональности и используемых инструментов.
