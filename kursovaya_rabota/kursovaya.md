# Курсовая работа по дисциплине «Информационные технологии»

## Тема
Разработка сайта ювелирной мастерской «Огранка».

## Исполнитель
- **ФИО:** Гурняк Александра
- **Группа:** 9/2-РПО-25/3

## Цель проекта

Создать адаптивный сайт ювелирной мастерской, который знакомит посетителей с изделиями и услугами, позволяет подобрать параметры кольца и отправить заявку на консультацию или изготовление.

## Краткое описание выполненной работы

В рамках проекта разработан сайт «Огранка», включающий каталог моделей колец, конструктор с выбором параметров и предварительным расчётом стоимости, информационные разделы об услугах мастерской и форму отправки заявок.

Отправка заявок настроена через Google Apps Script с сохранением данных в Google Таблицу. Для анализа посещаемости подключена Google Analytics 4. Для представления аналитических данных создан дашборд в Yandex DataLens.
