# Курсовая работа «Огранка»

**Дисциплина:** Информационные технологии  
**Исполнитель:** Гурняк Александра  
**Группа:** 9/2-РПО-25/3

## О проекте

«Огранка» — учебный проект сайта ювелирной мастерской. Сайт предназначен для знакомства с изделиями, выбора параметров кольца и отправки заявок на изготовление или консультацию.

## Основные возможности

- Каталог из 18 моделей колец.
- Конструктор кольца с выбором параметров и предварительным расчётом стоимости.
- Информация об услугах мастерской, гравировке и мастер-классах.
- Раздел с рекомендациями по подбору размера.
- Форма отправки заявок с сохранением обращений в Google Таблицу.

## Используемые инструменты

В проекте применены веб-технологии для создания сайта, Google Таблицы и Apps Script для обработки заявок, Google Analytics 4 для сбора веб-аналитики и Yandex DataLens для визуализации данных.

## Примечание о готовности

Telegram-бот представлен как визуальный прототип. Автоматическая обработка команд бота не реализована. Интеграция Instagram/ManyChat в рамках проекта не выполнялась.
