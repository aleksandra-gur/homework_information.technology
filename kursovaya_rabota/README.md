# Курсовая работа «Огранка»

**Дисциплина:** Информационные технологии  
**Исполнитель:** Гурняк Александра  
**Группа:** 9/2-РПО-25/3

## О проекте

«Огранка» — учебный проект сайта ювелирной мастерской. Сайт предназначен для знакомства с изделиями, выбора параметров кольца и отправки заявок на изготовление или консультацию.

## Основные возможности

| Раздел | Реализованные возможности |
|---|---|
| Каталог | Просмотр 18 моделей колец |
| Конструктор | Выбор параметров кольца и предварительный расчёт стоимости |
| Услуги | Информация о гравировке, мастер-классах и услугах мастерской |
| Подбор размера | Рекомендации по определению размера кольца |
| Заявки | Отправка обращений через форму сайта с сохранением в Google Таблицу |
